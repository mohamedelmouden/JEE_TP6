# TP JEE – Application CRUD avec Spring Boot & Thymeleaf
Description
--
Application web CRUD (Create, Read, Update, Delete) développée avec Spring Boot et Thymeleaf, permettant la gestion d'utilisateurs (nom et email) avec persistance dans une base de données MySQL.


# Technologies utilisées

Technologie  
--
Spring Boot 
Spring Data JPA 
Hibernate
Thymeleaf
MySQL
Maven

# Fonctionnalités & Routes :
- /signup   ## GET ##   Afficher le formulaire d'ajout 
- /adduser  ##  POST  ##  Sauvegarder un nouvel utilisateur
- /edit/{id}  ##  GET  ##  Afficher le formulaire de modification
- /update/{id}  ##  POST  ##  Mettre à jour un utilisateur
- /delete/{id}  ##  GET  ##  Supprimer un utilisateur
